# 🪼 くらげファイト 〜深海をただよう〜

タップでふわっと浮かび、サンゴをよけて真珠を集める、育成＆アクションゲーム。
クラゲを育て、ずかんを埋めて深海の奥へ。

## 公開ページ

https://kuuuu33.github.io/kurage-fight/

制作物一覧: https://kuuuu33.github.io/

## 遊びかた

- タップ / クリックでクラゲが浮かびます。サンゴと敵をよけて進みます
- 真珠を集めると、ずかん（スキン）の解放や「つよくする」に使えます
- ミッション、称号（見習いクラゲ〜伝説のクラゲ）あり
- オープニングの「くらげの水槽」は、育てたクラゲを眺められる待機画面です

### ステージ制

全6ステージ。**珊瑚を決まった本数くぐる → ボス登場 → 一定時間たえきる → クリア**で1プレイが完結します。
ステージNのボスを倒すとステージN+1が解放。クリア済みは何度でも再挑戦できます（真珠稼ぎ用）。

| # | ステージ | 珊瑚 | ボス | 耐久 | ギミック |
|---|---|---|---|---|---|
| 1 | 浅瀬のサンゴ礁 | 16本 | ハサミガニ | 20秒 | — |
| 2 | 海藻の森 | 20本 | ヌシウツボ | 24秒 | 動く珊瑚／手前でゆれる海藻で視界が遮られる |
| 3 | 沈没船 | 22本 | サビダコ | 28秒 | ＋機雷／**サーチライト**（明るいときだけ当たる） |
| 4 | 熱水噴出孔 | 24本 | マグマエイ | 30秒 | ＋電気クラゲ／**上昇気流**で押し上げられる |
| 5 | 発光生物の層 | 28本 | ダイオウイカ | 34秒 | ＋魚群／**まわりが暗く、光の範囲だけ見える** |
| 6 | 深淵 | 32本 | シンエンアンコウ | 40秒 | **全部のせ＋最速**（ラスボス） |

サーチライトは明滅していて、暗いあいだは通り抜けても安全です。暗闇の層は進行方向（右）に明かりを寄せてあり、ボス戦中は相手が見えるように暗さが弱まります。

ステージごとに水の色・光の差し込み・漂うもの・障害物の形・BGMが変わります。

### ハートとむずかしさ

- 1プレイに ❤️2（やさしいは ❤️4）。被弾で1つ減り、**1.2秒の無敵＋点滅**。0でゲームオーバー
- むずかしさはステージセレクトで切替。やさしいは当たり判定がさらに甘く、スクロールも遅め
- クラゲの当たり判定は**見た目の62%**（やさしいは52%）。珊瑚も描画より内側でしか当たりません
- 開発用: コンソールで `__kurageHitbox(true)` を実行すると当たり判定が可視化されます

### デイリーチャレンジの表示

水槽ホームのデイリーカードは右上の ✕ で消せます。消すと下のボタン列に「📅 デイリー」が出るので、そこから戻せます（未受け取りの報酬があるときは ✨ が付きます）。この設定は `kurage-dailyhide` に保存されます。ゲームオーバー画面とクリア画面のデイリーは消せません。

### 称号

攻略のふしめで上がります。エンドレスをやめた結果、旧しきい値（スコア35以上）が到達不能になっていたため付け替えました。

見習いクラゲ → ステージ1〜6をクリアするごとに1つずつ昇格（6層クリアで「深淵をのぞく者」）→ **全6ステージをノーダメージでクリアで「伝説のクラゲ」**。
旧データでスコアが高かった人が降格しないよう、昔の基準での位を下限として保持します。

### 層別ベスト

ステージセレクトの各カードに、クリア回数・ベストタイム・その層で稼いだ最高真珠・ノーダメ達成のバッジが出ます。

### ボス図鑑

「ずかん」の 👹ボス タブ。未撃破はシルエット＋「???」、撃破すると 生息ステージ・解説・初撃破日・撃破回数・ベストタイムが記録されます。

### タマゴガチャ

水槽ホームの「🥚 ガチャ」から。**1回 300真珠／10回 2700真珠**（10回は★3以上が1体かくてい）。
卵がふるえ、ひびが入り、光がもれて割れます。レアなほど光が強く、割れる前から気配が分かります。画面タップでスキップ可。

- レア度は ★1 42% ／ ★2 30% ／ ★3 18% ／ ★4 7.5% ／ ★5 2.5%
- **30回引くと★5かくてい**（天井）
- すでに持っている子とかぶったら真珠に還元（★1=20 … ★5=300）
- ずかんからの「むかえる」は200真珠、スキンの直接購入は90〜2700真珠。狙って買う道も残してあります

水槽で泳ぐのは最大16匹までです（10連で一気に増えても重くならないようにするため）。全頭は「だれであそぶ？」やおせわ画面から選べます。

### 個体の特性と色違い

クラゲ1匹ずつに**特性（パッシブ）**が付きます。効くのは出撃メンバーにしているあいだだけです。

| 特性 | 効果 | 出やすさ |
|---|---|---|
| 🫧 たからさがし / ⭐ のみこみが早い / 🍤 食いしんぼう | 真珠+15% / けいけんち+20% / エサ+30% | 各16% |
| 🧲 ひきよせ / 🛡️ かたいかさ | マグネット1.5倍 / 開始バリアが長い | 各14% |
| 🍀 しあわせもの | ときどき真珠が2個ぶん | 12% |
| 🐌 ゆうゆう | 流れが6%ゆっくり | 7%（レア） |
| ❤️ ふんばり | ハートが1つ多い | 5%（レア） |

**引き直し**はおせわ画面から **🫧250＋🍤20**。エサは今まで「ごはん」にしか使えず余りがちだったので、ここを出口にしました。真珠も買い切りで余らなくなります。

**色違い**は3%で生まれる特別な色（既存の色を色相回転させたもの・キラキラ付き）。ガチャ・タマゴ・むかえるのすべてに抽選があります。

### ミニゲーム

- **🧼 こけとり** — 水槽のクラゲをタップ →「こけとり」。15秒でガラスをこすってコケを落とします。達成率に応じて「きれい」「きげん」「けいけんち」と真珠が手に入ります
- **🎣 ふかうみつり**（1日1回）— 水槽ホームの「つり」から。左右に動くゲージがまんなかに来たらタップ。まんなかほど大あたりで、パーフェクトならずかんに新しいクラゲが追加されることも

単一の HTML ファイルで完結しています（外部依存なし）。

## 保存データについて

進捗はプレイヤーの端末に自動保存されます。サーバーには何も送信していません。

- **localStorage**（主）— 24キー、すべて `kurage-` 接頭辞
- **IndexedDB**（`kurage-save`）にミラー保存 — localStorageが消えても自動で復元します
- `navigator.storage.persist()` でブラウザに自動削除しないよう要求
- タイトル画面の「💾 データ」から**引き継ぎコード**でバックアップ・復元が可能

### セーブのバージョン

`kurage-savever` に保存形式のバージョンを持たせています（現在 `3`）。起動時に `migrateSave()` が走り、古いデータは中身を保ったまま読み替えます。

- **v2 でやっていること**: こうかん所の背景テーマ（🎮タブ）を廃止し、購入済みだった人に真珠を1回だけ返金。ステージ進捗が無いデータは「ステージ1のみ解放」で読み込み
- **v3 でやっていること**: 個体に特性と色違いを導入。すでにいる子にもさかのぼって抽選して付与（経験値・なまえ・スキンはそのまま）
- 仕様を変えるときは `SAVE_VER` を上げて `migrateSave()` に分岐を足してください。**既存キーの削除・意味の変更はしないこと**

### 改造するときの注意

- **キーを増やすのは安全。名前や保存する中身の形を変えるのは危険** — 既存プレイヤーのデータが読めなくなります
- `index.html` の `KEYS` 配列に載っているキーだけが IndexedDB にバックアップされます。**保存項目を追加したら、必ず `KEYS` にも追記してください**
- 新しいキーは必ず `kurage-` で始めること。`kuuuu33.github.io` 配下の作品はすべて同じオリジンで保存領域を共有しているため、接頭辞がないと他の作品のデータを壊します

## ホーム画面への追加

`icons/` と `manifest.webmanifest` を置いてあるので、ホーム追加するとアイコンが正しく出ます。

ゲーム内にも案内があります（`index.html` 末尾の独立した `<script>`。ゲーム本体には手を入れていません）。

- **データひきつぎ画面**に常設の手順（スマホのときだけ表示）
- **ゲームオーバー時に1回だけ**出るおすすめバナー。`kurage-best` が5以上、または `kurage-pearls` が10以上のときだけ。初回プレイ直後には出しません
- 追加ずみ（`navigator.standalone` など）やPCでは出しません
- 閉じると `kurage-a2hs` に記録して二度と出しません

iOS Safari は7日間ひらかないと保存データを消すことがありますが、**ホーム画面から起動していれば対象外**です。この案内は体裁ではなくセーブデータを守るためのものなので、消さないでください。
